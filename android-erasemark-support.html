Android Support

EraseMark is an Android app for removing visible watermarks with on-device image processing.

Getting started

  1. Select an image with the Android photo picker.
  2. Choose Precise Text, Area Removal, or Clone Area.
  3. Mark the area and start processing. An interstitial ad may appear before processing.
  4. Preview and export the result when satisfied.

Improving results

Cover only the watermark whenever possible. For complex backgrounds, use Clone Area to copy a nearby clean region. If needed, undo and try again with a smaller brush.

Advertising

The app shows banner and interstitial ads. If an ad does not load, check your internet connection and try again; image processing itself remains local.

Android 使用支持

EraseMark（清除水印）是一款在 Android 设备本地处理图片可见水印的工具。

基本操作

  1. 通过 Android 系统图片选择器选择图片。
  2. 选择文字精准、区域清除或区域复制。
  3. 标记需要处理的位置并开始处理；处理前可能展示插页广告。
  4. 预览结果，满意后导出。

改善处理效果

尽量只覆盖水印本身；复杂纹理建议使用附近干净区域进行区域复制。效果不理想时，可撤销并缩小画笔重试。

广告

App 会展示横幅广告和插页广告。广告未加载时请检查网络后重试；图片处理本身仍在设备本地完成。
