Support

EraseMark is an iPhone app for removing visible watermarks with on-device image processing.

Getting started

  1. Select an image from Photos.
  2. Choose Precise Text, Area Removal, or Clone Area.
  3. Mark the area you want to process and preview the result.
  4. Export the image when you are satisfied.

Improving results

Cover only the watermark whenever possible. For complex backgrounds, use Clone Area to copy a nearby clean region over the watermark. If needed, undo the result and try again with a smaller brush.

使用支持

EraseMark（清除水印）是一款在 iPhone 本地处理图片可见水印的工具。

基本操作

  1. 从照片中选择图片。
  2. 选择精准涂抹、区域清除或区域复制。
  3. 标记需要处理的位置并预览结果。
  4. 满意后导出到照片。

改善处理效果

尽量只覆盖水印文字本身；复杂纹理建议使用附近干净区域进行区域复制。对结果不满意时，可撤销并缩小画笔重新处理。
